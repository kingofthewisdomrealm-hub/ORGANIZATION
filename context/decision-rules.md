# Decision Rules

1. **No new repo** unless it survives a 48-hour “would I still care?” test and has a clear first milestone.
2. Every active project must have a single next physical action written in this ORGANIZATION repo.
3. Once a week: kill or park anything that has not moved in 14 days.
4. Revenue or audience-building projects (COVENANT, delegationeconomy, speaking) always beat pure research.
5. Keep root instruction files short (< ~200 lines). Use progressive disclosure via context/ and skills/.
6. Prefer read-only tool access for high-risk systems (ad budgets, payments, client data).
