# ORGANIZATION — AI Operating System / Master Command Center

**Owner:** Josias (kingofthewisdomrealm-hub)  
**Purpose:** Single source of truth for every project, decision, and AI agent that runs the business and life systems.

This repo is intentionally simple markdown files so any agent harness (Claude Code, Co-work, Codex, OpenClaw, Grok) can load it and work.

## Quick Start for Humans
1. Open this folder in Claude Code / Co-work / your preferred harness.
2. The agent will automatically load `AGENTS.md` / `CLAUDE.md` and `memory.md`.
3. Talk to the **Executive Assistant** first: “Run my daily pulse” or “What’s the single next move today?”
4. Before building software: “Run Open Source Scout” — skill at `skills/open-source-scout/`, library at `project-command-center/OPEN_SOURCE_ARSENAL.md`.

## Structure
- `AGENTS.md` / `CLAUDE.md` — Always-on instructions for every agent
- `memory.md` — Living preferences and corrections (self-improving)
- `context/` — Deeper background loaded on demand
- `departments/` — Specialized agents (Executive Assistant is live first)
- `skills/` — Reusable SOPs (global + department-level)
- `project-command-center/` — Inventory, focus, arsenal, opportunity maps
