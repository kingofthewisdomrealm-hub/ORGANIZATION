# License guide

Always identify the license from the LICENSE file. Classify before recommending.

SAFE / PERMISSIVE — MIT, Apache-2.0, BSD, ISC. Generally fine in hosted products.

REVIEW REQUIRED — MPL (file-level copyleft), LGPL, BSL, SSPL, Commons Clause. Explain the obligation. Do not say commercially safe.

STRONG COPYLEFT — GPL, AGPL-3.0. A modified AGPL app that the public uses over a network can require offering source. Twenty CRM is AGPL. Prefer Atomic CRM (MIT) for convenantbuilderscrm unless AGPL is explicitly accepted.

UNKNOWN — no LICENSE, source-available, custom. Treat as blocked.
