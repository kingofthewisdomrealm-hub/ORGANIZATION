# Project Pulse Skill

## Goal
Give Josias a 60-second clear picture of momentum so he can decide where to put attention.

## Steps
1. Check the latest `context/current-focus.md` and `project-command-center/GITHUB-PROJECT-INVENTORY.md`.
2. Focus only on the engines: delegationeconomy / yourspecificthing and COVENANT.
3. For each: last meaningful activity, open risks, single next physical action.
4. Flag anything that has gone quiet >14 days (candidate for park/kill).
5. End with one recommended focus for the next 2–4 hours.

## Output Format
- Short bullets
- Plain English
- One clear recommendation at the bottom
